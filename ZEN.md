Zen of Vervision

Vervision is a context router, not a project brain.

The agent should reason.
Vervision should make the right evidence cheap to find.

Point to knowledge before carrying knowledge.

Reveal context progressively:
concise by default, detailed on demand.

Metadata should help decide what to read.
It should not become another burden to read.

Prefer a few relevant results over many possible results.

When Vervision does not know, it should say so.
Uncertainty is information; invented certainty is noise.

Use deterministic signals when deterministic signals are enough.

Do not add intelligence where paths, metadata, hashes, revisions, dependencies, or explicit rules can solve the problem reliably.

Freshness is evidence of change, not proof of correctness.

A document being "FRESH" does not make it true.
A document being "STALE" does not make it false.

Stable knowledge and temporary progress are different things.
Keep them different.

Project knowledge belongs to the project.

Human-readable project files are the source of truth.
Indexes, caches, and derived state should be disposable and rebuildable.

Never lock useful project knowledge inside Vervision.

Optimize information flow, not tool-call count.

A cheap extra call is often better than expensive irrelevant context.

Do not force an agent to read what it can reliably decide it does not need.

Give agents evidence, clear boundaries, and useful next actions.
Do not prescribe their reasoning path without necessity.

Every feature must earn its complexity.

Prefer changes that materially improve accuracy, context efficiency, reliability, or usability.

If a simpler mechanism can solve the same problem, prefer the simpler mechanism.

If a feature makes Vervision smarter but the workflow heavier, question it.

Do not preserve obsolete scaffolding merely because earlier agents needed it.

If a stronger model makes a mechanism unnecessary, remove the mechanism.

The better the agent becomes, the thinner Vervision should be.

The ideal Vervision response contains exactly enough information for the agent to know what to inspect next — and no more.

Simple does not mean primitive.
Simple means unnecessary mediation has been removed.

Route precisely. Reveal progressively. Stay out of the way.
