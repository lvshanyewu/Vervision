AGENTS.md

Vervision is a local-first context-routing tool for AI agents.

Its job is to help agents find the right project knowledge with as little unnecessary context as possible. It is a context router, not a project brain.

Prefer:

- precise routing over broad retrieval;
- progressive disclosure over eager loading;
- deterministic mechanisms over unnecessary intelligence;
- simple, inspectable designs over additional abstraction.

Do not replace agent reasoning when the agent can make the decision reliably itself.

For substantial changes involving architecture, retrieval, MCP behavior, context management, metadata design, or product direction, read "ZEN.md".

For non-trivial development tasks, use Vervision itself when useful to locate relevant project knowledge. Do not load every handoff document by default.

Treat Vervision output as routing evidence rather than mandatory workflow. When documentation, indexes, and repository reality disagree, inspect the actual repository and resolve the inconsistency.

Keep stable knowledge separate from temporary progress.

As agents become stronger, Vervision should become thinner rather than more prescriptive.

Complete the requested work, perform appropriate verification, and update lasting project knowledge when the change makes existing knowledge materially outdated.
